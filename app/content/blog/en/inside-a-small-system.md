This example is a place to document a design decision. Replace the content below with something you have actually built or investigated.

## Context before tools

Describe the people who will use the system, the task it should help them complete, and the constraints that matter. A small system still deserves a clear purpose.

## Make the tradeoffs visible

| Decision     | What to explain                         |
| ------------ | --------------------------------------- |
| Scope        | What belongs in the first version?      |
| Design       | Why does this approach fit the problem? |
| Verification | What evidence shows that it works?      |

## The next iteration

End with the remaining questions. A project does not need to be finished to have useful lessons to share.
